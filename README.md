# 👁️ Blink Controlled Robot using Arduino & L298N

A real-time assistive robotics project that enables hands-free robot control using eye blinks. The system detects muscle signals (EOG/ECG-based input) and translates them into directional movements.

---

## 🚀 Features

- 👁️ Eye blink detection using analog sensor input
- 🧠 Signal smoothing and adaptive baseline filtering
- ⚡ Real-time blink classification
- 🎯 Custom command mapping:
  - 1 Blink → Forward
  - 2 Blinks → Backward
  - 3 Blinks → Right
  - 4 Blinks → Left
- ⏱️ Time-controlled motor execution
- 🔒 Auto-stop safety mechanism
- 🧪 Noise reduction & debounce logic

🧠 How It Works

1. The sensor captures electrical signals generated by eye blinks.
2. Signals are smoothed using a moving average filter.
3. A dynamic baseline is calculated to reduce noise.
4. When signal deviation crosses a threshold → blink detected.
5. Number of blinks within 2 seconds determines movement.
6. Motors run for a fixed duration and stop automatically.

▶️ How to Run

1. Upload code using Arduino IDE
2. Keep sensor stable for initial calibration
3. Perform blinks to control robot:
   - 1 blink → forward
   - 2 blinks → backward
   - 3 blinks → right
   - 4 blinks → left

---

⚠️ Important Notes

- Adjust `spikeThreshold` (60–110) based on noise
- Ensure proper sensor placement near eye muscle
- Use stable power supply to avoid false triggers
