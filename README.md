# Eye-Blink-Controlled-Robot
Developed an Eye Blink Controlled Robot that interprets blink signals into directional commands using microcontroller-based embedded systems.

⚙️ Features :
 Eye blink detection-based control
 Multiple movement commands (Forward, Backward, Left, Right)
 Real-time signal processing
 Useful for assistive robotics applications
 Low-cost and efficient hardware implementation 

Technologies Used :
Embedded Systems
Microcontroller (Arduino / similar)
IR Sensor / Eye Blink Sensor
Motor Driver (L298N)
C/C++ (Arduino Programming).

Applications :
Assistive devices for disabled individuals
Robotics automation
Human-machine interaction systems.
